# 合同功能验收基线

本基线依据 2026 年 6 月 15 日签署的《承担陈伟教授国家项目在线语料库网站设计和建设协议书》，只覆盖合同明确要求的在线语料库功能。ChatAI、音视频多模态、Whisper 和模型管理不属于验收范围。

| 序号 | 合同功能 | 验收证据 |
|---|---|---|
| 1 | 分级账号、授权、数据库连接、流量控制 | 用户角色、语料等级和单独授权；上传与导出配额；Nginx 按 IP 请求速率和连接数限制 |
| 2 | 在线语料和个人语料 | 教师、演示、个人语料模型；单语、平行、词性标注等类型；管理员登记和用户上传流程 |
| 3 | ParaConc 对齐、双语条件和排序 | 句段对齐、双向检索、包含/排除条件、置信度、L1-R5 三级排序、结果导出 |
| 4 | AntConc 主要工具 | KWIC、Plot、Cluster、N-Gram、Collocate、Keyword、Wordcloud |
| 5 | CQBweb 类检索、统计、历史和保存 | 普通/条件/CQP 查询、前后缀/包含/通配符/POS、分页排序、LL/卡方、历史和受容量限制的保存 |
| 6 | 图表展示 | 条形/柱状、柱线、散点气泡、箱线、发散条形和词云 |
| 7 | 结果保存到硬盘或 U 盘 | 授权检索结果导出为 TSV，图表导出为 PNG/SVG，由浏览器选择本地保存位置 |
| 8 | Corpus documentation | 元数据、文档、段句、词元、词型、加工和版权信息 |
| 9 | 反馈和 Bug 报告 | 用户反馈提交、列表、详情和状态管理 |

预置语料的实际数量、七阶段归类和内容正确性属于数据验收：乙方提供最终语料后，应通过管理员登记或 manifest 流程导入，并运行固定语料金标准回归测试。软件验收不得以未提供的生产语料替代代码功能测试。

## 交付物

- 网站源代码：本仓库及锁定依赖文件。
- 网站使用说明书：`docs/USER_GUIDE.md`。
- 网站建设和测试报告：验收执行后生成的正式 DOCX 报告。
